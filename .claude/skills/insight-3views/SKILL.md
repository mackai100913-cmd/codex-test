# インサイト3視点フレーム（恒久ルール）

発注者の指示：**「筋トレ／美容などのインサイトを考えるときは、必ず3つの別視点でカードに落とすこと。今後も毎回この3つを念頭に置いて出力する」**

## 3つの視点（必ず全部そろえる）

対象テーマ（例：筋トレをする人／美容を気にする男性／ある成分／ある商品仮説）について、**独立した3枚のカード**を出す。1枚に混ぜない。視点がかぶったら考察が足りていない。

### ① 論文から（Evidence）
- 査読論文・学会誌・政府/大手調査会社のデータを根拠にする
- 「誰の・いつの・何という研究で・どんな数値か」を明示（出典URL・年）
- 手元にエビデンスがなければ WebSearch で取りに行く。憶測を論文視点に混ぜない
- カード例：「筋トレ継続動機の因子分析（日本健康教育学会誌2019）で体力向上4.02・体型維持3.98が上位。"モテたい"は主動機でない」

### ② リサーチドリブン思考（Market/Behavior）
- 市場データ・競合・行動観察から「まだ言語化されていない需要」を推論する
- 「市場が空いている／密集している」「関心と実践のギャップ」など構造で語る
- カード例：「男性美容は"モテ"でなく"減点回避（清潔感）"。関心はあるが実践しない摩擦を、剤型と言い換えで解ける」

### ③ 5WHY（Root Cause）
- 表層の行動から「なぜ？」を5回繰り返し、真因（本質的インサイト）まで掘る
- 必ず「なぜ1〜5→真因」の連鎖を残す。1段で止めない
- カード例：「なぜ筋トレ→体を変えたい→なぜ→自信→なぜ→加齢で自信が揺らぐ→なぜ→評価が外見と結びつく→なぜ→コントロールできる資産が身体→真因：自己効力感（自分でコントロールできる感覚）の回復」

## 出力フォーマット

インサイト系の問いには、必ず以下の3枚をこの順で出す：

```
【①論文】 …（出典付き）
【②リサーチドリブン】 …（市場構造で）
【③5WHY】 なぜ1→…→なぜ5→真因：…
```

そのうえで、3枚から見える**統合インサイト1行**と、そこから派生する**アイデアの種**を添える。

## 商品開発の順序（発注者ルール）

- **金額（原価・価格）より先に「どんな商品を作るか」を考える。** 固定概念を外してアイデアの種を広げる段階では、実現可能性・コストで刈り込まない
- 発散が済んでから、別途 原価・届出・調達の検証（Track-E方式）に回す
- カードに落とすときは idea_studio（種別＝insight/idea/question）や card_index に入れられる粒度で書く

## 適用範囲

「若さを保つ（見た目＋中身）」を北極星とする機能性D2Cサプリの企画全般。筋トレ・美容・アンチエイジング・成分・ターゲット動機を論じるすべての出力に適用する。
