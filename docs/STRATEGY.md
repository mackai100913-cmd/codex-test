# グルメTikTok フォロワー20万 成長戦略

ロールモデル `@buzz_meshi`（バズ飯系グルメ）から抽出した「伸びる型」を、
本リポジトリの自動生成パイプラインに落とし込んでいます。

## ロールモデルから抽出した勝ちパターン

バズ飯系グルメアカウントに共通する要素（公開情報・一般的なグルメTikTok分析より）：

1. **冒頭1秒で結論** … 表紙＝最強の一皿＋強いフック文（`copywriter` が生成）
2. **極太・フチ付きの大きな文字** … スマホで一瞬で読める（`image_generator` で焼き込み）
3. **店名・エリア・価格・特徴を必ず明記** … 「行ける情報」にする（情報スライド）
4. **シズル感** … 湯気・照り・断面・伸びるチーズ（Gemini画像プロンプトに内蔵）
5. **保存導線** … 「保存して後で行く」CTAでアルゴリズム評価UP（caption）

> 注: TikTokは直接スクレイピングできなかったため、上記は「バズ飯/グルメTikTok」の
> 一般的なベストプラクティスに基づく型です。実アカウントの傾向に合わせて
> `config/persona.yaml` `config/content_themes.yaml` を編集すれば即反映されます。

## KPIとロードマップ（0 → 20万）

| フェーズ | フォロワー | 主眼 | 投稿頻度 |
|---|---|---|---|
| 立ち上げ | 0–1,000 | 型の確立・投稿習慣 | 1日2本 |
| 初速 | 1,000–1万 | 保存率・完視聴率の最適化 | 1日2–3本 |
| 拡大 | 1万–5万 | シリーズ化・エリア網羅 | 1日2本＋まとめ投稿 |
| 加速 | 5万–20万 | コラボ・トレンド便乗・店舗タイアップ | 1日2本維持 |

### 重視する指標
- **保存率**（最重要・再訪意図） / **完視聴率** / **シェア率** / プロフィール遷移率

## 運用の自動化

- `python run.py` で日次の投稿パッケージを自動生成
- `.github/workflows/daily-content.yml` で **毎日定刻に自動生成**（GitHub Actions）
  → 生成物をアーティファクトとして受け取り、スマホで投稿するだけ
